# Higher English Grammar PWA

Progressive Web App covering **Chapters XVI–XX** from *A Text-Book of Higher English Grammar*:

- Verbals / Non-Finite Verbs (Infinitives, Gerunds, Participles)
- Auxiliary, Defective & Anomalous Verbs (Be, Have, Do, Must, May, Can, Dare, Need, Ought, Shall/Will)
- Tenses in Conditional Sentences (Type I, II, III)
- Sequence of Tenses

## Features

- Complete rules with **Bengali explanations**
- Clean educational UI (blue theme)
- **100-Question Exam Mode** — click any question to reveal the answer + বাংলা note
- Category filters (Infinitives, Participles, Gerunds, Auxiliaries, Conditionals, Sequence)
- Installable PWA (works offline)

## How to run

1. Clone the repo
2. Open `index.html` in a browser, **or**
3. Serve with any static server:
   ```bash
   npx serve .
   ```
4. On mobile/desktop Chrome → **Install App** / Add to Home Screen

## Enable GitHub Pages (for live demo)

1. Go to repository **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / root
4. Save — app will be live at:
   `https://pbwsantu-collab.github.io/higher-english-grammar-pwa/`
